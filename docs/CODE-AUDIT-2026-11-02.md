# TES3NP alpha source audit — 2026-11-02

**Branch:** `Update/v0.1.21-alpha`
**Scope:** the complete Git-tracked source and build tree was inventoried (AutoHotkey entry point/modules, C# Chat Host, PowerShell/Python helpers and tests, GitHub workflows, documentation, assets and patch manifest). The full text of live modules and relevant code/feature references was inspected through GitHub. Binary artwork, game assets, and the supplied markerless TES3MP executable were inventoried, **not** executed, decompiled, or relicensed. The previously user-verified baseline is NP Expansion Pack v0.2 successfully installed and TES3MP connecting to the server.

## Removed after reachability checks

1. **Retired scheduler** — deleted `src/app/daily-login-scheduler.ahk` (1,225 lines / 48 functions), its root include, saved-event initialization, scheduled-login timers, event editor, F8 countdown logic, missed-event polling, shutdown bookkeeping, and the launcher-settings entry shim. Scheduler was still executing from startup even though its menu button had been hidden.
2. **Scheduler-dependent session states** — removed scheduled keep-open/multi-login, auto-claim/close, batch queue and follow-up callbacks from `src/game/session.ahk` and `src/game/expansion-mismatch.ahk`. Manual character launch, one-at-a-time login monitoring, up to four simultaneously running TES3MP clients, real game recovery, login progress, and the original plugin-mismatch capture remain.
3. **Retired portable backup fields** — removed event/hotkey export, restore, and parsing from `src/data/backup.ahk`; kept v1 character-backup compatibility (including old backups containing extra, now-ignored scheduler sections), encrypted live credentials, favorite restoration and profile data. Existing player `settings.ini` files are **not** silently erased or migrated; old keys remain inert.
4. **Disconnected UI** — removed the permanently hidden full-width Launch Character control (the front-page favorite quick launch and per-row Play remain); removed the unreachable Launch All & Close dialog and its one-time notice setting, the dead Troubleshooting popup/duplicate broad diagnostic report, and an unused older accessibility-reset callback. Retained `SetBookControlVisible` by moving it into the active `v016-refinements.ahk` settings UI instead of deleting a shared helper.
5. **Broken legacy developer-only packaging path** — removed the unused `python scripts/project.py package` source-ZIP subcommand that expected a no-longer-existing integer `AppConfig.Build`. `python scripts/project.py check` and the actual `scripts/build-windows.ps1` package/release workflow remain unchanged.
6. **Unnecessary embedded artwork** — excluded source-only `assets/icons/species/*.png` masters and `assets/icons/tes3np.png` from generated AutoHotkey runtime resources. The files remain in source control for artwork editing; runtime species ICOs and active UI backgrounds are still embedded. Added a Windows package check that these PNG originals are not extracted.
7. **Stale test/docs references** — removed a retired scheduled-login fixture stub and queue field from the standalone mismatch test; corrected old session/release test instructions and outdated `docs/ASSETS.md` entry for the already-removed `og-creatures-overlay.png`.

## Deliberately retained — referenced/active or required source evidence

- **Manual quick launch, profile editor, favorite controls, character backup/import, launch watchdog, and four-client limit** are all live. The additional manual client sessions are independent; the retired automatic batch queue is not.
- **Game Chat/WebView2 and Happy Hour** use live timers and message-driven refresh; the JavaScript `schedule()` for Discord card refresh is a debounce mechanism, **not** the removed character/event scheduler.
- **Installed Macros** intentionally keeps an *invisible* ListView as a selection/data model. Removing that ListView would break Run/Stop/Remove interactions despite its being visually hidden.
- **Expansion Pack v0.2 import** (ZIP or extracted folder, staging, hashes, backup/rollback, Win32 transient lock handling, atomic progress/result INIs) is the latest user-confirmed successful workflow. This audit does not modify it. Bundled `patches/expansion-pack` and `patches/manifest.json` are still needed by the **active** older installer/repair path and are therefore not dead assets.
- **Legacy Install / Repair and Restore Backup** remain reachable through the tray/patcher and first-run setup and cannot be indiscriminately removed without redesigning onboarding. **Known risk:** old bundled v0.1 repair can overwrite the separately imported v0.2 files; avoid running that repair after v0.2 installation until a safeguard/update is designed.
- **Source-only artwork PNGs, markerless TES3MP research patch, licenses, test fixtures, update/release helpers and historical changelog** are retained as editable originals, provenance/release compliance material, or supported developer workflows—not active launcher runtime.
- **`OpenLauncherDataFolder`, `SanitizeDiagnosticPath`, and the current Launcher Data/Copy Logs controls** remain because active UI/update code references them. Do not resurrect the deleted standalone Troubleshooting GUI.

## Static safety guards

`scripts/project.py check` now refuses reintroduced scheduler functions, event/hotkey UI, queue fields, batch-only config defaults, orphan Launch All & Close controls, dead troubleshooting panel, and includes; it also checks that manual launch entry points and the shared themed-control visibility helper remain. The existing checks still cover AHK delimiters/includes/duplicate declarations, favorite selection, macro layout, required UI artwork and SHA-256 of each manifest payload. `scripts/check-chat-architecture.py` continues to guard Chat Host behavior, Expansion Pack safety and the AppData reset lifecycle. The Windows packaging script now asserts that runtime icon ICOs exist but source-only PNG masters were excluded.

## Validation limits and Windows acceptance steps

**Completed:** GitHub source inspection, definition/reference trace of retired functions across live AHK modules, tree inventory, targeted source assertions, commits on the existing alpha branch, and documented verification gates.
**Not completed here:** execution of the complete Python/PowerShell checks on a Windows checkout, fresh AHK compilation, Windows GUI/runtime tests, manual server connection on the newly cleaned build. Do **not** characterize those as passed before local results.

Run `git pull --ff-only` on the current alpha checkout, then `Build tes3np.bat`. Its existing preflight runs Python source/architecture checks, test import fixtures, PowerShell syntax, C# compile, AHK parser fixtures and packaging. On a successful build, start `tes3np.exe` and check: (1) normal launcher and character list spacing; (2) first character auto-favorite and one-time switch message; (3) per-row Play and front-page quick launch, with a second manually launched game permitted up to four clients; (4) gold login progress and recovery; (5) no scheduled timers, popups or old hidden controls; (6) macros and backup/export/import including an older portable backup; (7) Chat Host/Game Chat, Happy Hour and launcher settings; (8) installed Expansion Pack v0.2 still allows server login; (9) safe failure/rollback diagnostics. Do not run old Install / Repair as a validation shortcut.

**Next development after this cleanup passes:** address the reachable legacy Install / Repair downgrade risk with a separate, reversible and verified design. Keep the previous confirmed v0.2 baseline available for rollback.
