# tes3np

**tes3np** is a Windows launcher for the Morrowind multiplayer server [Nerevarine Prophecies](https://wiki.nerevarineprophecies.com/).

![tes3np launcher in v0.1.20-alpha](https://raw.githubusercontent.com/IAmShawn98/tes3np-releases/main/images/Launcher-v0.1.20.png)

*The screenshot shows v0.1.20-alpha. This README previews v0.1.21-alpha.*

## Features

- **Manage Characters** — Save up to 10 characters, pick a favorite, and watch the login steps as tes3np enters your details. Run up to four game clients at once.
- **Game Chat and Happy Hour** — Read live Discord chat and see how much time is left in an active Happy Hour.
- **Expansion Pack** — Download the optional pack from the official Discord channel or install it from a ZIP or extracted folder.
- **Manage Macros** — Import, run, and stop AutoHotkey scripts and ZIP macro packages. You can also link an installed Windows app.
- **Character Backups** — Export your characters, login delays, and favorite to move them to another PC.
- **Game Client Settings** — Use the bundled TES3MP client or select a custom one.

## Download

Open [**Releases**](https://github.com/IAmShawn98/tes3np-releases/releases) and download the versioned Windows ZIP. The v0.1.21-alpha file will be named `tes3np-v0.1.21-alpha-windows.zip`. The public download is currently v0.1.20-alpha.

## Requirements

- Windows 10 or 11, 64-bit.
- [Morrowind Game of the Year Edition](https://en.uesp.net/wiki/Morrowind:Morrowind) with Tribunal and Bloodmoon.
- Microsoft Edge WebView2 Runtime for Game Chat.

The Windows ZIP includes TES3MP 0.8.1 and AutoHotkey v2.

## Install

1. Extract the entire Windows ZIP into its own folder.
2. Run `tes3np.exe`. If asked, choose your Morrowind GOTY folder.
3. Open **Manage Characters** to save a character, or choose **Start New Adventure** to log in manually.

## Update

Click the version number in the launcher to check for updates. You can review the release notes before downloading and installing. Keep your `%APPDATA%\tes3np` folder so your characters and preferences carry over.

## Troubleshooting

[Report a launcher problem](https://github.com/IAmShawn98/tes3np-releases/issues/new/choose) with your tes3np version, Windows version, and what you did before the issue appeared. For a log excerpt, open **Launcher Settings → Launcher Data → Copy Launcher Logs**. Review screenshots and logs for personal details before sharing. Character exports contain passwords, so keep them private.
